<h2><strong>Ensuring Data Portability</strong></h2>
<p>When healthcare providers switch from one HIMS to another, they must maintain
access to patient records and service recipient data for safety and continuity
of care. This requires accurate and complete data migration between HIMS.</p>
<p><strong><u>The Code of Practice for Data Portability</u></strong>, developed
by MOH in consultation with relevant stakeholders, sets out MOH's minimum
expectations for Data Migration.</p>
<p>This Code sets out practices that you must comply with when providing
Data Portability support or services and advocates best practices across
the health information technology industry. As good practice, you and your
healthcare provider clients should consider exit strategies that include
comprehensive data migration and handling procedures. All HIMS listed on
<a href="https://cms.synapxe.sg/sites/connectnehr/Pages/Integration-Status.aspx" rel="noopener noreferrer nofollow" target="_blank">Status of System Integration with the NEHR</a>on Synapxe’s official website
comply with this requirement.</p>
